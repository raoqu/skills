# Source Code Structure Template

Write `doc/source-code-structure.md` with this structure:

## 1. 目录总览

- 按顶层目录说明用途
- 点出真正重要的目录，忽略低价值噪音

## 2. 关键源码路径解析

- 逐个解释核心目录/包/模块
- 说明每个路径负责什么
- 说明哪些目录属于公共能力、业务能力、基础设施能力

## 3. 入口与调用关系

- 标出程序入口、初始化链路、核心调用路径
- 对 monorepo 说明 package 之间的依赖方向

## 4. 配置、脚本与工程化文件

- 说明配置目录、脚本目录、CI/CD、代码生成、测试基建等文件的作用

## 5. 阅读建议

- 给出新读者的推荐阅读顺序
- 标出最值得先看的文件和原因

## Writing guidance

- 直接引用真实路径。
- 不要把目录树全文复制进文档；应以解释和归纳为主。
- 如果目录层级很深，只展开关键分支。
